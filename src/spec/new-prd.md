# PRD: WIFI QR 코드 카드 생성기

## 1. Product overview

### 1.1 Document title and version

- PRD: WIFI QR 코드 카드 생성기
- Version: 1.0

### 1.2 Product summary

이 문서는 매장이나 개인 사용자가 WIFI 네트워크 정보를 쉽게 공유할 수 있도록 QR 코드 카드를 생성하는 웹 서비스의 요구사항을 정의합니다. 사용자는 간단한 정보 입력만으로 맞춤형 WIFI QR 코드 카드를 만들고 이미지 파일로 다운로드하여 출력하거나 온라인으로 공유할 수 있습니다.

이 서비스는 복잡한 설정 없이 누구나 쉽게 사용할 수 있도록 미니멀하고 직관적인 사용자 인터페이스를 제공하는 것을 목표로 합니다. 사용자는 브랜드 이름, 네트워크 이름(SSID), 비밀번호, 원하는 배경색을 입력하여 즉석에서 QR 코드 카드를 생성하고 미리 볼 수 있습니다.

## 2. Goals

### 2.1 Business goals

- 사용자가 쉽고 빠르게 WIFI QR 코드를 생성할 수 있는 도구를 제공합니다.
- 매장 등에서 WIFI 정보 공유 편의성을 높여 고객 경험을 개선합니다.
- 서비스 하단의 레이블을 통해 'toycrane' 브랜드 인지도를 간접적으로 높입니다.

### 2.2 User goals

- WIFI 네트워크 이름(SSID)과 비밀번호를 포함하는 QR 코드를 쉽게 생성합니다.
- 원하는 브랜드 이름과 배경색을 적용하여 카드를 시각적으로 맞춤 설정합니다.
- 생성된 QR 코드 카드를 이미지 파일로 다운로드하여 오프라인에서 사용합니다.
- 모바일 기기에서 QR 코드를 스캔하여 쉽게 WIFI에 접속합니다.

### 2.3 Non-goals

- 사용자 계정 생성 또는 로그인 기능 제공.
- 복잡한 카드 디자인 템플릿 또는 이미지 업로드 기능 제공.
- 생성된 QR 코드의 사용 통계 추적 또는 분석 기능 제공.
- 다국어 지원.

## 3. User personas

### 3.1 Key user types

- 소규모 매장 주인 (카페, 식당 등)
- 개인 사용자 (집, 소규모 사무실)
- 이벤트 주최자 (컨퍼런스, 워크샵)

### 3.2 Basic persona details

- **매장 주인**: 매장을 방문하는 고객에게 WIFI 접속 정보를 쉽고 세련되게 제공하고자 합니다.
- **개인 사용자**: 집이나 개인 작업 공간의 WIFI 정보를 방문객과 편리하게 공유하고 싶어합니다.
- **이벤트 주최자**: 행사 참가자들이 행사장 WIFI에 쉽게 접속할 수 있도록 안내 자료에 포함할 QR 코드가 필요합니다.

### 3.3 Role-based access

- **일반 사용자**: 모든 사용자는 별도의 로그인 없이 서비스의 모든 기능(정보 입력, QR 코드 생성, 배경색 변경, 이미지 다운로드)을 이용할 수 있습니다.

## 4. Functional requirements

- **WIFI 정보 입력** (Priority: High)
  - 사용자는 네트워크 이름(SSID)을 입력할 수 있어야 합니다.
  - 사용자는 WIFI 비밀번호를 입력할 수 있어야 합니다. (비밀번호가 없는 개방형 네트워크도 지원)
- **브랜드 정보 입력** (Priority: High)
  - 사용자는 카드 하단에 표시될 브랜드 이름을 입력할 수 있어야 합니다.
- **배경색 선택** (Priority: Medium)
  - 사용자는 미리 정의된 색상 팔레트 또는 색상 코드를 입력하여 카드 배경색을 변경할 수 있어야 합니다.
- **QR 코드 생성** (Priority: High)
  - 입력된 SSID와 비밀번호 정보를 바탕으로 WIFI 접속용 QR 코드를 생성해야 합니다.
- **카드 레이아웃 적용** (Priority: High)
  - 카드 상단에는 "WIFI 접속" 문구가 표시되어야 합니다.
  - 카드 중앙에는 생성된 QR 코드가 표시되어야 합니다.
  - 카드 하단 중앙에는 입력된 브랜드 이름이 표시되어야 합니다.
  - 카드 하단 오른쪽 구석에는 "by toycrane" 레이블이 작게 표시되어야 합니다.
  - 카드는 지정된 크기(너비 256px)와 비율(3:4)로 렌더링되어야 합니다.
- **실시간 미리보기** (Priority: High)
  - 사용자가 정보를 입력하거나 변경할 때마다 카드 미리보기가 실시간으로 업데이트되어야 합니다.
- **이미지 다운로드** (Priority: High)
  - 사용자는 생성된 카드를 고해상도 이미지 파일(예: PNG)로 다운로드할 수 있어야 합니다.

## 5. User experience

### 5.1. Entry points & first-time user flow

- 사용자는 웹사이트 URL을 통해 서비스 페이지에 직접 접속합니다.
- 별도의 가입 절차 없이 바로 정보 입력 필드와 카드 미리보기가 표시됩니다.

### 5.2. Core experience

- **정보 입력**: 사용자는 페이지에 표시된 입력 필드에 브랜드 이름, 네트워크 이름(SSID), 비밀번호를 순서대로 입력하고 배경색을 선택합니다.
  - 각 입력 필드에는 명확한 레이블과 예시(placeholder)를 제공하여 사용자 입력을 돕습니다. 입력 형식 오류 시 실시간 피드백을 제공합니다.
- **미리보기 확인**: 정보가 입력됨에 따라 카드 미리보기가 실시간으로 업데이트되어 최종 결과물을 즉시 확인할 수 있습니다.
  - 미리보기는 실제 다운로드될 카드와 동일한 디자인과 레이아웃을 보여줍니다.
- **다운로드**: 사용자는 완성된 카드 디자인에 만족하면 '이미지로 다운로드' 버튼을 클릭합니다.
  - 버튼 클릭 시 즉시 이미지 파일 다운로드가 시작됩니다.

### 5.3. Advanced features & edge cases

- 비밀번호가 없는 개방형 WIFI 네트워크 QR 코드 생성 지원.
- 매우 긴 브랜드 이름 또는 SSID 입력 시 카드 레이아웃이 깨지지 않도록 처리 (예: 글자 크기 자동 조절 또는 말줄임표 표시).
- 다양한 특수문자가 포함된 비밀번호 처리.

### 5.4. UI/UX highlights

- 미니멀하고 깔끔한 디자인.
- 직관적인 정보 입력 방식.
- 입력과 동시에 결과를 확인할 수 있는 실시간 미리보기.
- 원클릭 이미지 다운로드 기능.

## 6. Narrative

카페 사장님인 김민지 씨는 손님들이 WIFI 비밀번호를 자주 물어보는 번거로움을 겪고 있습니다. 손님들이 직접 QR 코드를 스캔하여 접속할 수 있는 방법을 찾던 중, 이 WIFI QR 코드 생성 서비스를 발견했습니다. 민지 씨는 서비스 페이지에 접속하여 카페 이름과 WIFI 정보, 그리고 카페 인테리어와 어울리는 따뜻한 베이지색 배경을 선택했습니다. 몇 초 만에 예쁜 QR 코드 카드가 만들어졌고, '이미지로 다운로드' 버튼을 눌러 카드를 저장했습니다. 이제 민지 씨는 이 카드를 인쇄하여 테이블마다 비치해두었고, 손님들은 더 이상 비밀번호를 묻지 않고 편리하게 WIFI를 이용하며 만족해합니다.

## 7. Success metrics

### 7.1. User-centric metrics

- 주간/월간 순 방문자 수 (Unique Visitors).
- QR 코드 카드 생성 완료 수.
- 생성된 카드 이미지 다운로드 수.
- 평균 세션 시간.

### 7.2. Business metrics

- 서비스 총 이용 횟수.
- 소셜 미디어 또는 블로그 등 외부 채널에서의 서비스 언급 빈도 (간접 측정).

### 7.3. Technical metrics

- 페이지 평균 로딩 속도.
- QR 코드 생성 및 이미지 다운로드 성공률.
- 클라이언트 측 에러 발생률.
- 서버 응답 시간 (해당되는 경우).

## 8. Technical considerations

### 8.1. Integration points

- 클라이언트 측 QR 코드 생성 라이브러리 (예: `qrcode.react` 또는 유사 라이브러리).
- HTML 요소를 이미지로 변환하는 라이브러리 (예: `html2canvas` 또는 유사 라이브러리).

### 8.2. Data storage & privacy

- 사용자 입력 데이터(SSID, 비밀번호, 브랜드 이름 등)는 서버에 저장되지 않고 전적으로 클라이언트 측 브라우저에서 처리됩니다.
- 사용자의 개인 정보 보호를 최우선으로 고려합니다.

### 8.3. Scalability & performance

- 대부분의 로직이 클라이언트 측에서 실행되므로 서버 부하가 적어 초기 확장성이 용이합니다.
- 이미지 생성 프로세스가 클라이언트 리소스에 미치는 영향을 최소화하도록 최적화합니다.
- 웹사이트 에셋(이미지, 스크립트, 스타일시트)을 최적화하여 빠른 페이지 로딩 속도를 보장합니다.

### 8.4. Potential challenges

- 다양한 브라우저 및 디바이스에서의 일관된 사용자 경험 보장 (Cross-browser compatibility).
- 특수문자가 포함된 WIFI 비밀번호 처리 시 QR 코드 호환성 문제.
- 고해상도 디스플레이(Retina 등)에서도 선명한 카드 이미지 생성.

## 9. Milestones & sequencing

### 9.1. Project estimate

- Small: 1-2주

### 9.2. Team size & composition

- Small Team: 1 개발자 (프론트엔드 중심)

### 9.3. Suggested phases

- **Phase 1**: 핵심 기능 구현 (1주)
  - 주요 deliverables: 기본 입력 폼 (SSID, 비밀번호, 브랜드 이름), QR 코드 생성 로직, 기본 카드 레이아웃 (고정 배경색), 실시간 미리보기 기능.
- **Phase 2**: 부가 기능 및 디자인 완성 (1주)
  - 주요 deliverables: 배경색 변경 기능, 카드 이미지 다운로드 기능, 최종 디자인 적용 (미니멀 스타일, 폰트, 레이아웃 정교화), 반응형 디자인 고려.

## 10. User stories

### 10.1. WIFI 정보 및 브랜드 이름 입력

- **ID**: US-001
- **Description**: 사용자는 WIFI QR 코드 카드를 만들기 위해 네트워크 이름(SSID), 비밀번호, 브랜드 이름을 입력하고 싶습니다.
- **Acceptance criteria**:
  - SSID 입력 필드가 제공됩니다.
  - 비밀번호 입력 필드가 제공됩니다. (입력 내용 가리기 옵션 포함)
  - 브랜드 이름 입력 필드가 제공됩니다.
  - 각 필드에는 안내를 위한 placeholder 텍스트가 표시됩니다.

### 10.2. 카드 배경색 선택

- **ID**: US-002
- **Description**: 사용자는 생성될 카드의 배경색을 원하는 색으로 변경하고 싶습니다.
- **Acceptance criteria**:
  - 배경색을 선택할 수 있는 인터페이스(예: 색상 팔레트 또는 색상 코드 입력)가 제공됩니다.
  - 배경색을 선택하면 카드 미리보기의 배경색이 실시간으로 변경됩니다.
  - 기본 배경색이 설정되어 있습니다.

### 10.3. QR 코드 및 카드 실시간 미리보기

- **ID**: US-003
- **Description**: 사용자는 입력한 정보와 선택한 배경색이 적용된 QR 코드 카드의 최종 모습을 실시간으로 확인하고 싶습니다.
- **Acceptance criteria**:
  - 정보(SSID, 비밀번호, 브랜드 이름, 배경색)가 변경될 때마다 카드 미리보기가 즉시 업데이트됩니다.
  - 미리보기에는 "WIFI 접속" 문구, QR 코드, 브랜드 이름, "by toycrane" 레이블이 정확한 위치에 표시됩니다.
  - 미리보기 카드는 256px 너비와 3:4 비율을 유지합니다.
  - 입력된 SSID와 비밀번호로 생성된 유효한 WIFI 접속 QR 코드가 표시됩니다.

### 10.4. 카드 이미지 다운로드

- **ID**: US-004
- **Description**: 사용자는 완성된 QR 코드 카드를 이미지 파일로 다운로드하여 저장하거나 인쇄하고 싶습니다.
- **Acceptance criteria**:
  - '이미지로 다운로드' 버튼이 제공됩니다.
  - 버튼을 클릭하면 현재 미리보기에 표시된 카드가 고해상도 PNG 이미지 파일로 사용자의 기기에 다운로드됩니다.
  - 다운로드된 이미지 파일명은 예측 가능하고 의미 있는 이름(예: `wifi-qr-card.png`)으로 설정됩니다.

### 10.5. 카드 레이아웃 확인

- **ID**: US-005
- **Description**: 사용자는 생성된 카드에 필요한 모든 요소(텍스트, QR코드, 레이블)가 정확한 위치와 디자인으로 표시되는지 확인하고 싶습니다.
- **Acceptance criteria**:
  - 카드 상단 중앙에 "WIFI 접속" 텍스트가 표시됩니다.
  - 카드 중앙 영역에 QR 코드가 충분히 크게 표시됩니다.
  - 카드 하단 중앙에 입력된 브랜드 이름이 표시됩니다.
  - 카드 하단 오른쪽 구석에 "by toycrane" 레이블이 작은 크기로 표시됩니다.
  - 모든 텍스트 요소는 가독성이 좋은 폰트로 표시됩니다.
