# WIFI QR 코드 카드 생성기 PRD

## 1. 제품 개요

매장에서 사용할 수 있는 WIFI QR 코드 카드를 생성하고 다운로드할 수 있는 웹 서비스입니다.
미니멀한 디자인으로 제작되어 어떤 매장에서도 잘 어울리는 카드를 제작할 수 있습니다.

## 2. 핵심 기능

### 2.1 카드 생성

- 입력 정보
  - 브랜드 이름
  - 네트워크 이름 (SSID)
  - 비밀번호
  - 카드 배경색

### 2.2 카드 디자인

- 크기: 256px (가로:세로 = 3:4 비율)
- 레이아웃
  - 상단: "WIFI 접속" 텍스트
  - 중앙: QR 코드
  - 하단: 브랜드 이름
  - 우측 하단: "by toycrane" 레이블 (작은 크기)
- 커스터마이징
  - 배경색 변경 가능

### 2.3 다운로드

- 생성된 카드를 이미지 파일로 다운로드 가능
- 이미지 포맷: PNG (투명도 지원)

## 3. 기술 요구사항

### 3.1 프론트엔드

- Next.js 프레임워크 사용
- Shadcn UI 컴포넌트 라이브러리 활용
- QR 코드 생성 라이브러리 필요
- 이미지 다운로드 기능 구현
- React Hook Form을 사용한 폼 상태 관리
  - Zod를 사용한 폼 유효성 검증
  - TypeScript 타입 안정성 확보

### 3.2 디자인 가이드라인

- 미니멀리즘 디자인 원칙 준수
- 가독성 높은 폰트 사용
- 적절한 여백과 정렬로 시각적 균형 유지
- QR 코드 스캔이 용이하도록 충분한 크기 확보

## 4. 사용자 시나리오

1. 사용자가 웹사이트 접속
2. 필요한 정보 입력 (브랜드명, WIFI 정보, 배경색)
3. 실시간으로 카드 미리보기 확인
4. 원하는 디자인으로 조정
5. 이미지 다운로드
6. 매장에서 출력하여 사용
